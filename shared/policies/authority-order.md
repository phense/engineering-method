# Authority Order

Resolve instructions and evidence in this order:

1. Explicit current user instruction.
2. Project-specific gates and protected controls.
3. Current specifications, code, tests, and repository state.
4. The canonical project backlog or issue system.
5. Retrieved project memory.
6. Native host memory.

Project gates include repository instructions, constitutions, contribution rules,
architecture decisions, CI requirements, and protected controls. Surface a
material conflict between equally authoritative project rules; methodology
selection does not authorize inventing a ruling. Treat memory as context and
verify it against current repository evidence before acting on it.
