# Engineering Method 0.3.2

Released 2026-11-13. A maintenance release: unscripted routing evaluations
and a fix for host runs that timed out without output.

## Changes

- Syncs [Method Core](https://github.com/phense/method-core) revision `64d9a02`
  (72 files).
- Adds `scripts/run_natural_evals.py`. It sends a case prompt exactly as
  written, with every given plugin loaded, and reports which skills the host
  loaded on its own over a number of runs. The routing harness
  (`scripts/run_host_evals.py`) keeps telling the host to select a workflow;
  the new runner shows what happens without that instruction.
- Adds three unscripted cases under `evals/natural/`: a failing test, a
  feature across three modules and a typing error.
- `run_host_evals.py` no longer lets the host inherit an open standard input.
  Codex then waited for more input, and the run timed out without one event.
- No skill name, description or behaviour changes.

## Verification and limits

The complete Python suite passes 359 tests on macOS. `scripts/validate-plugin`
and `sync-core --check` pass. The committed-source package is built twice for
reproducibility.

Unscripted requests, three runs per case with Writing Method loaded beside
this plugin, the hosts' coordinator models, and on Codex the plugins as
installed (Claude Code 2.1.323, Codex CLI 0.169.0):

| Request | Expected | Claude | Codex |
|---|---|---|---|
| A failing test | `systematic-debugging` | 2 of 3 | 3 of 3 |
| A feature across three modules | a specification skill | 3 of 3 | 3 of 3 |
| A typing error in a README | no skill | 3 of 3 | 2 of 3 |

Three runs show a tendency, not a rate. The Codex figures are a re-scoring of
saved transcripts after the runner learned to count a skill read inside a
compound command. An earlier single probe in which each request ended with a
request for a plan loaded no specification skill on Claude: asking for a plan
first lowers loading. The paid routing and lifecycle evaluations of the
release gate were not rerun; the evidence limits of [0.3.0](0.3.0.md) remain.

The downloadable package is `engineering-method-0.3.2.zip`; verify it with the
attached `SHA256SUMS`.

## Install or update

```sh
claude plugin marketplace update engineering-method
claude plugin update engineering-method@engineering-method
```

```sh
codex plugin remove engineering-method@engineering-method
codex plugin add engineering-method@engineering-method
```

Restart the host session afterwards. See
[Installation and maintenance](../installation.md) for a fixed-tag install and
[OpenCode installation](../opencode.md) for the source-linked loader.
