# Engineering Method 0.1.1

Released 2026-09-11. This patch adds a native OpenCode adapter and installer for
all 17 shared Engineering Method skills. It supports a Mac-hosted OpenCode
session accessed from T3 on another computer, including DeepSeek sessions.

## Changes

- Additive native plugin hook registers the original skills and host instructions.
- Source-linked installation preserves relative script/resource paths and existing
  provider, permission and MCP configuration.
- Guarded check, idempotent install and exact-byte owned uninstall; foreign or
  modified loaders and symlinked destination parents are refused.
- Host adapter describes actual delegation, model and recovery boundaries.
- Installation docs cover native OpenCode, T3 helper refresh and removal.

## Verification and acceptance

The integration has 317 passing local tests and independent code review. Native
OpenCode 1.18.30 discovered all 17 skills, and DeepSeek Flash loaded
`verification-before-completion` and executed a harmless verification command.
The user additionally confirmed skill loading from T3 on Windows with the Mac
as execution host. See [EM-008 evidence](../verification/EM-008-opencode.md).
Release validation includes a reproducible committed-source package and isolated
Claude/Codex native installation; the attached checksum identifies the release
archive. Existing shared skills and Claude/Codex adapters are unchanged.

The [historical 0.1.0 acceptance](../verification/EM-005-acceptance.md) retains its
original limits. No new full lifecycle, multi-agent or compaction acceptance is
claimed for OpenCode. Automatic Flash/Pro selection and agentic-rag lifecycle
hooks are separate work and are not included in this plugin release.

## Install or update

Use [installation and maintenance](../installation.md) for Claude/Codex and
[OpenCode installation](../opencode.md) for the source-linked loader. Keep the
OpenCode source checkout at its installed path and restart the helper/start a
fresh thread after an update. The downloadable package is
`engineering-method-0.1.1.zip`; verify it with the attached `SHA256SUMS`.
