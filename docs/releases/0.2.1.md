# Engineering Method 0.2.1

Released 2026-09-18. This patch refines the existing local Quarto/Typst PDF
workflow. It changes presentation and rendered-output verification without
adding a new lifecycle skill or changing the Markdown composition contract.

## Changes

- Uses a restrained dark-navy editorial hierarchy with a 1 pt chapter rule.
- Gives the cover and contents separate pages and removes the running footer
  from the cover.
- Uses 12 pt body text, 28 mm side margins, a narrower reading measure and
  controlled heading and paragraph spacing on A4 pages.
- Replaces chapter badges with typographic numbers and strengthens the cover,
  contents and subheading hierarchy.
- Extends native regression checks for the cover, contents placement, accent
  rule, text size, line measure, navigation, page totals and source preservation.

The design rationale, Typst/LaTeX comparison and institutional sources are in
the [EM-016 design record](../verification/EM-016-pdf-design.md) and
[template design guide](../../templates/documentation/pdf/DESIGN.md).

## Verification and limits

The complete Python suite passes 319 tests. Native Quarto 1.10.18 and Typst
0.15.1 rendering passes for English and German five-page samples and a
nine-page reordered 120-row table. The plugin validators, Python compilation,
shell syntax and whitespace checks pass. The committed-source package is built
twice for reproducibility and installed in disposable Claude and Codex
configurations without credentials or live model requests before publication.

All five English sample pages and the stress-table continuation were visually
inspected. This is bounded sample evidence, not PDF/UA conformance or a claim
that arbitrary future content needs no visual review. Helvetica Neue and Menlo
remain the verified macOS fonts. The unchanged routing, lifecycle and OpenCode
claims retain the evidence limits documented for [0.2.0](0.2.0.md).

The downloadable package is `engineering-method-0.2.1.zip`; verify it with the
attached `SHA256SUMS`.
